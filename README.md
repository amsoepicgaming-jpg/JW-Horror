# JW Horror

A horror-themed virtual instrument project by JW Audio Labs.

**Status:** Development. No verified plugin build or Payhip release yet.

Target formats: Windows/macOS VST3, macOS AU, and standalone.

Design direction: glowing skull, pumpkins, spiderwebs, 16 spooky sound slots, synthesizer controls and effects.

The original promotional artwork is concept art, not a screenshot of a functioning plugin.
